# Mapa de empatía · Jefe de almacén
> Punto de partida con las hipótesis del equipo. Confirmar o corregir cada celda con las entrevistas.

| Dimensión | Hipótesis a confirmar |
| --- | --- |
| Piensa y siente | Teme que el sistema diga una cosa y el almacén tenga otra; le preocupa que le atribuyan la pérdida. |
| Ve | Cajas moviéndose todo el día, registros en sistema o planillas, diferencias que aparecen al contar. |
| Escucha | Reclamos de gerencia o contabilidad por faltantes; explicaciones del personal sobre las diferencias. |
| Dice y hace | Cuenta manualmente, concilia registros, busca el origen del descuadre sin una prueba clara. |
| Dolores | Mermas que no se sabe dónde ocurrieron; tiempo perdido en conteos; falta de evidencia. |
| Ganancias | Saber qué entró y salió con prueba en foto; detectar diferencias a tiempo; menos pérdidas. |
