# POV y preguntas de diseño

Documento elaborado el 20/11/2026 a partir de las tres notas E01-E03. No es un acta de una reunión ocurrida antes de esta fecha.

## Punto de vista

Un jefe de almacén que combina sistemas con documentos físicos necesita registrar oportunamente las entradas y salidas y reconstruir las diferencias de inventario con evidencia, porque la regularización tardía y la investigación manual dificultan explicar los faltantes y afectan el despacho.

Usuario: jefes y encargados entrevistados. Necesidad: registro oportuno y trazabilidad. Insight: tener un ERP o cámaras generales no garantiza que se registre cada movimiento ni que se pueda explicar una diferencia. Fuentes: E01-P1/P3/P4, E02-P1/P4/P6 y E03-P1/P3/P4.

## Preguntas «¿Cómo podríamos...?»

1. ¿Cómo podríamos registrar cada entrada o salida sin depender de transcribir vales al final del día? (E01-P1, E02-P1, E03-P1).
2. ¿Cómo podríamos asociar una imagen al movimiento para encontrar el origen de una diferencia? (E01-P4, E02-P4, E03-P4).
3. ¿Cómo podríamos advertir una discrepancia antes de que retrase un despacho? (E01-P3).
4. ¿Cómo podríamos mostrar la evidencia y explicar el conteo para que el usuario pueda revisarlo antes de ajustar stock? (E01-P7 y necesidad derivada de P4).
5. ¿Cómo podríamos incorporar el sistema sin aumentar la carga operativa ni generar rechazo del personal? (E02-P6/P7).
6. ¿Cómo podríamos mantener una solución sencilla frente al polvo, mantenimiento y costo? (E03-P6/P7 y E01-P7).
